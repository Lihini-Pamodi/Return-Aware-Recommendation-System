# Return-Aware Recommendation Systems

## Project Title
Dynamic Real-Time Intervention to Reduce Product Return Rates in E-commerce Using Pre-Purchase Behavioral Signals

## Description
This research project investigates how pre-purchase behavioral signals can be used to predict product returns and improve recommendation quality in e-commerce platforms.

## Dataset
The primary dataset used in this study is:

**Amazon Fashion Dataset**
- Source: Amazon Product Data
- Category: Amazon Fashion
- Contains product information, ratings, reviews, and customer feedback data.

## Research Objectives
- Analyze customer review and product information data.
- Identify indicators associated with product dissatisfaction and returns.
- Develop a return-aware recommendation framework.
- Evaluate the impact of return prediction on recommendation quality.
